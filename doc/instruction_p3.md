# 実装指示書 P3: 試験一式をランダムな安全点で往復させる

`doc/plan.md`、`doc/format_v0.md`、`doc/report/p1.md`・`p1b.md`・`p2.md` を先に読む。
この段はスコープの 5: **mruby 付属の試験一式 (`vendor/mruby/test/t/*.rb` と、使う
gem の試験) を、外からランダムな安全点で止めて書き出し、復元して続けた結果が、
往復なしと完全に一致するか**。「どこで止めても正しく運べる」証拠を作る。

## 決まったこと

- 死んだレジスタ (命令列から見て、もう読まれずに上書きされるか使われないレジスタ) は、
  書き出すときに nil にする (2026-11-03 ユーザ、P2 の検収)。バイトコードから生きている
  レジスタを計算する。計算は書き出す瞬間だけ (普段の実行には何もしない)。
- 形式は v0 のまま (足すものがあれば `doc/format_v0.md` に追記)。

## やること

1. **外からの停止**: プログラムが `Checkpoint.save` を呼ばなくても、命令の境目の
   ランダムな地点で書き出しを起こす仕組みを、**試験のビルドだけ**に入れる
   (普段のビルドには入れない)。乱数の種と「何回目の安全点か」を記録し、同じ種で
   同じ地点を再現できること。方式 (既存の安全点の判定へ印を立てる、mrdb の
   命令ごとの hook を試験のビルドだけで使う、など) は選んで理由を report に。
2. **往復**: 止めた地点で書き出し → 新しい `mrb_state` (同じプロセス) に復元 →
   古い状態は捨てて、復元した側で続ける。これを 1 回の実行で何度も (たとえば平均
   N 命令ごと) 繰り返す。別のプロセス・32bit との往復も、少ない数でよいので混ぜる。
   書き出しを断られた地点 (C の境目の中、Fiber の中など) は、断った理由を数えて
   そのまま続ける。
3. **比べ方**: 往復なしの実行と、試験の結果 (通った・落ちた試験の名前と数、出力) が
   完全に一致すること。object_id・時刻・乱数など、復元で変わってよいものに依存する
   試験が見つかったら、その試験と理由を表にして除外する (黙って除外しない)。
4. **結果の数字**: 試験ごとに、試みた地点の数・書き出せた数・断った数 (理由ごと)・
   往復後に結果が食い違った数。食い違いは全部、種と地点を記録し、原因を調べて直す
   (直せないものは理由を書いて残す)。
5. **死んだレジスタ**: 生きているレジスタの計算を入れ、P2 で「SabiRuby に無い物を
   古いレジスタが指していて断った」場面が減るかを確かめる。
6. **できれば SabiRuby も**: 試験一式の一部を、C で書いた像を SabiRuby で続ける形で
   回す (`SABIRUBY_DIR` があるとき)。数は少なくてよい。SabiRuby に手を入れる
   必要があれば、worktree (`SABIRUBY_DIR` に渡すもの、ブランチ
   `feature/checkpoint`) で feature `checkpoint` の下に。
7. `rake test` に、短い版 (数十秒で終わる、種を固定) を足す。長い版は別の rake の
   タスク (`rake fuzz` など) にし、種・回数を引数で渡せるようにする。

## 触ってよい範囲

- このリポジトリと、SabiRuby の worktree (上) だけ。`vendor/mruby` は触らない
  (試験のビルド用の patch は `patches/` に、試験のビルドだけに当たるように)。

## 止まる条件

- 食い違いの原因が、形式か方式の作り直し (論理グラフの考え方・permanent の引き当て・
  安全点の条件) を要すると分かったとき。直し方の案を書いて返す。
- mruby 本体の VM・GC に大きな改造が要るとき。
- sudo・パッケージの追加が要るとき。

- コミット: このリポジトリは `main`、SabiRuby は `feature/checkpoint` (英文、

  話を書かない。終わったら worktree の `target/` を `cargo clean` で消す。
- 普段のビルドの `vm.c` の patch を変えたら、valgrind の命令数で前後を比べる
  (時間では判定しない。docker のイメージ `ghost-valgrind` が手元にある)。
- report は `doc/report/p3.md`: 外からの停止の方式、生きているレジスタの計算、
  試験ごとの数字の表、除外した試験と理由、見つけた食い違いと直したこと、直せなかった
  もの、SabiRuby の結果、残件。
